## Synthetic CSV quality demonstration

Open `csv-quality/sample-report.html` for the standalone report and `csv-quality/README.md` for the schema, limits and reproduction commands. Python 3.10+ and the standard library are sufficient. The package includes the source, focused tests, two invented CSV fixtures and JSON findings.

The included two-file batch produced 5 checked records, 9 findings and 0 input errors, with exit code 1 because findings are expected. Multiple findings can concern the same record. It checks five documented rule categories for one fixed format; it does not establish measurement validity, customer results, production integration, large-scale performance or demand. The demo and report were prepared with AI assistance and verified against the included synthetic fixtures and focused tests.

A paid CSV project first needs an authorized input format, agreed checks and output, budget, deadline and acceptance criteria. Its scope and fee are separate from the G1 offer.
