# ley — locomotion simulation diagnostic

Independent robotics developer. Contact: yaoqia2678@163.com

This website contains a bounded diagnostic offer and an attributed work sample using Unitree's official G1 pretrained policy. It does not contain customer code, weights, private logs or the internal business dashboard.

The sample measures three deterministic 30-second runs in MuJoCo. Unitree provided the policy and robot assets; ley did not train this policy. Measurement tooling and reporting were prepared with AI assistance and verified through local simulation runs. There is no physical-robot or Go2 validation claim, and these three runs do not establish a population success rate.

Open `index.html` for the pilot offer and `sample-report.html` for measurements, limitations and a separate continuous 15-second recording. The two-page PDF is available without account registration. The original, already-reviewed PDF is retained unchanged.
